HTML Tutorial

Introduction to HTML

HTML stands for HyperText Markup Language. It is used to create and structure web pages.

Basic HTML Structure

<html>
<head>
    <title>My Web Page</title>
</head>
<body>
    <h1>Hello World</h1>
</body>
</html>

Important HTML Tags

  • <h1> - Heading
  • <p> - Paragraph
  • <a> - Hyperlink
  • <img> - Image
  • <table> - Table
